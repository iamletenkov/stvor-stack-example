# История стека-примера

Раздел текущей версии портал показывает на карточке релиза («Что изменилось»). Раздел `## <версия>` обязателен:
без него `scripts/release.sh render` не соберёт релиз.

## 1.0.0

- Компоненты: api 1.0.0 (Python, стандартная библиотека), web 1.0.0 (Node.js без зависимостей).
- Страница показывает версии, имя робота, цвет, наличие секрета `api_token` и число запусков api.
- Параметры: `DEMO_ROBOT_LABEL` (имя робота, заполняется автоматически), `DEMO_COLOR` (по умолчанию `blue`).
- Секрет `api_token` — файл, страница показывает только, задан ли он.
- Данные: счётчик запусков в именованном томе `demo-data`; схема данных 1, миграций нет.
- Совместимость: linux/amd64 и linux/arm64, агент Stvor не ниже 5.12.0.
